# Практические работы по Flutter

В каталогах practice_4 — practice_8 находятся отдельные Flutter-приложения для Android.

Для запуска откройте нужный каталог, выполните `flutter pub get`, затем `flutter run` на подключённом Android-устройстве или эмуляторе. Требуются Flutter SDK с Dart 3.13.5 и Android SDK.
